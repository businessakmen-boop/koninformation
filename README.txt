KON-WEB — обновлённая версия сайта

В комплект входят:
- адаптивная главная страница;
- анимированная 3D-сцена с человеком, поднимающимся по лестнице;
- локальная форма подготовки сообщения без серверной отправки;
- политика обработки персональных данных;
- отдельное согласие на обработку персональных данных;
- условия использования материалов сайта;
- robots.txt и sitemap.xml.

Важно перед публикацией:
1. Форма подготавливает текст на устройстве посетителя и открывает системное меню отправки.
2. До подтверждения пользователем сведения не передаются сайту или владельцу.
3. Нельзя вставлять токен Telegram-бота в HTML или JavaScript сайта.
4. Старый раскрытый токен нужно отозвать через BotFather и выпустить новый. Сам бот при этом сохраняется.
5. Следует проверить уведомление Роскомнадзора и комплект внутренних документов оператора.
